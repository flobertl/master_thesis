# Inhalt
Ordner zum speichern von Phase 1 'Basismodell' des Bestimmen des Hyperparameterraums, anhand Daten von HH 1.

# Ordnerstruktur
Jedes Modell hat einen Ordner mit der Anzahl der States als Namen.

Modelle:
- Training: ein jahr (2019)
- Test: ein Jahr (2020)
- Evaluierung:
    - PIT Plots
        - Ganzes Test Jahr
        - einzelen Saisonen/Tageszeiten für Verzerrung
    - average Mean Error
